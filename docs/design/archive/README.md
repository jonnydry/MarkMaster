# Archived design plans

These documents describe the retired **Orbital theme** (`data-theme="orbital"`) and related cohesion work from early 2026.

MarkMaster now uses:

- **Light / dark** color mode
- **Accent color themes** (Horizon, Aurora, Ember, Nebula, Canopy, Pulse) via `data-color-theme`
- Independent **Monospace UI** typography toggle

The plans here are kept for historical context only. Do not implement against them without verifying the current theme system in `src/components/providers.tsx` and `src/app/globals.css`.
